# Loan Portfolio Analytics with Tableau

An interactive Tableau project that analyzes more than 15 years of business loan data in Israel.

The project was developed as part of a Business Intelligence course and focuses on transforming raw financial data into interactive dashboards and data stories that support business analysis and decision-making.

## Project Overview

This project explores the activity of a loan portfolio through two interactive dashboards and two storytelling-driven Tableau Stories.

The analysis answers key business questions such as:

- What is the overall size of the loan portfolio?
- How has the portfolio evolved over time?
- Which geographic areas receive the highest number of loans?
- How are loans distributed across different loan programs?
- What was the impact of the October 7th events on the organization's lending activity?

## Dashboards

### Dashboard 1 — Portfolio Overview

Provides a high-level overview of the loan portfolio through:

- KPI summary
- Dynamic measure selection
- Program and sub-program filtering
- Top locations analysis
- Time trend analysis
- Interactive Box Plot comparison between major loan programs

### Dashboard 2 — Geographic Analysis

Focuses on the geographic distribution of the portfolio.

Features include:

- Interactive map of Israel
- Dynamic measure selection
- Top locations ranking
- Scatter plot analysis
- Detailed information popup for every selected city
- Coverage indicators

## Stories

### Story 1 — Understanding the Loan Portfolio

Guides the user through four business questions:

1. How large is the portfolio?
2. How has it evolved over time?
3. Where is the activity concentrated?
4. How are loans distributed across programs?

### Story 2 — Impact of October 7th

Analyzes how the October 7th events affected lending activity by answering:

1. How did loan activity change?
2. Which emergency programs drove the increase?
3. Where was the emergency support concentrated?
